韓国語フラッシュカード v2.6 / BOOK01

学習操作を変更しました。

・「× もう一度」「○ 覚えた」を常時表示
・2つの判定ボタンを「日本語訳と読みを表示」より上に配置
・単語を見て意味を思い出せた場合、訳や例文を開かずにその場で「覚えた」を記録可能
・思い出せない場合も、訳を開く前に「もう一度」を記録可能
・日本語訳を確認した後でも、例文を開かずに判定可能
・例文、例文訳、例文解説は必要なときだけ開ける

推奨運用:
「覚えた」は、韓国語を見て日本語の意味を頭の中で言えたときに押してください。
曖昧だった場合は日本語訳を確認し、「もう一度」にする方が能動想起の学習として適切です。
