【ID設計】
id      : 教材に印刷されている参照番号。001〜910。
book_id : 教材の識別子。このアプリでは BOOK01。
uid     : アプリ内部で使う一意キー。BOOK01-001〜BOOK01-910。

画面には従来どおり id（001〜910）を表示します。
学習履歴・お気に入り・メモ・現在位置は uid で保存します。

【既存データの移行】
v2.3以前に id=001〜910 をキーとして保存された学習履歴等は、
v2.4の初回起動時に BOOK01-001〜BOOK01-910 へ自動移行します。
